# Quiver Mutation Database (QMD) — website (moved)

**This repository is no longer where the QMD website lives.**

The site has been folded into the backend repository as part of the migration
to Cloudflare Workers: one Worker now serves both the static frontend and the
API (same origin, `/api/*`).

- **Current home of the site:** the `public/` directory of
  [quivermutationdb/api](https://github.com/quivermutationdb/api)
- **Live site:** https://quivermutationdb.org

Please open issues and pull requests against `quivermutationdb/api`.
This repository is kept for history and will be archived.

---

QMD is an open research infrastructure for quivers, exchange matrices, and
mutation-equivalence classes arising in cluster algebras and representation
theory.
